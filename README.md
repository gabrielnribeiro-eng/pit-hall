
# 🏎️ PIT WALL - GP DE SÃO PAULO

### Projeto de HTML e CSS | Desafio Pit Wall

---

## 📌 Sobre o projeto

O **Pit Wall** é um site desenvolvido utilizando HTML5 e CSS3, inspirado no Grande Prêmio de São Paulo de Fórmula 1.

O objetivo do projeto é colocar em prática os conhecimentos adquiridos nas aulas de desenvolvimento web, criando uma página moderna, organizada, interativa e responsiva.

O site reúne informações sobre pilotos, classificação, circuito e ingressos.

---

## 🎯 Objetivos do projeto

- Praticar HTML5 e CSS3.
- Desenvolver uma página temática de Fórmula 1.
- Trabalhar com Flexbox e CSS Grid.
- Criar tabelas e formulários.
- Aplicar efeitos visuais e animações.
- Desenvolver um layout responsivo.
- Melhorar a experiência visual do usuário.

---

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Visual Studio Code
- Live Server
- Google Fonts (Titillium Web)

## 🏁 Estrutura do site

O site é dividido em seis partes principais:

### 1. Cabeçalho (Header)

- Logo Pit Wall.
- Menu de navegação.
- Botão "Garantir seu ingresso".
- Botão com destaque vermelho e efeito ao passar o mouse.

### 2. Tela inicial (Hero)

- Título GP de São Paulo.
- Texto de apresentação.
- Imagem temática de Fórmula 1.
- Faixa vermelha diagonal.
- Informações sobre o circuito.
- Botão "Garantir meu lugar".
- Botão "Ver classificação".

### 3. Pilotos

- Cards dos pilotos.
- Identificação das equipes.
- Números dos pilotos.
- Cores específicas de cada equipe.
- Efeitos de interação.

### 4. Classificação

- Tabela de classificação.
- Posições dos pilotos.
- Identificação das equipes.
- Filtros de pesquisa.
- Efeito ao passar o mouse nas linhas.

### 5. Ingressos

- Apresentação da área de ingressos.
- Informações e benefícios.
- Formulário para preenchimento de dados.
- Campos organizados em grade.

### 6. Rodapé (Footer)

- Identificação do projeto.
- Informações finais.

## 💻 Recursos de HTML e CSS utilizados

| Recurso | Aplicação |
|---|---|
| `:root` | Variáveis de cores e fontes |
| `display: flex` | Organização dos elementos |
| `justify-content: space-between` | Distribuição dos elementos |
| `display: grid` | Organização dos cards |
| `repeat(auto-fit, minmax())` | Adaptação automática dos cards |
| `.form-grid` | Organização do formulário |
| `.full` | Campo ocupando toda a grade |
| `<table>` | Tabela de classificação |
| `<thead>` | Cabeçalho da tabela |
| `<tbody>` | Corpo da tabela |
| `flex: 1` | Distribuição dos filtros |
| `@media` | Responsividade |
| `:hover` | Efeitos de interação |
| `transition` | Transições suaves |
| `linear-gradient()` | Degradês |
| `clip-path` | Recorte diagonal da imagem |
| `box-shadow` | Sombras dos elementos |

## 📱 Responsividade

O site foi desenvolvido para funcionar em diferentes tamanhos de tela.

Foram utilizadas duas media queries principais:

- `@media (max-width: 768px)`: adaptações para tablets e celulares.
- `@media (max-width: 400px)`: adaptações para celulares pequenos.

As adaptações incluem:

- Reorganização do cabeçalho.
- Ajuste dos tamanhos dos textos.
- Reorganização dos cards.
- Formulário em uma coluna.
- Rolagem horizontal da tabela.
- Ajustes dos botões.

## 🚀 Como executar o projeto

1. Abra o Visual Studio Code.
2. Abra a pasta `PIT-WALL`.
3. Verifique se os arquivos estão organizados corretamente.
4. Confira se a imagem está dentro da pasta `img`.
5. Abra o arquivo `index.html`.
6. Clique com o botão direito.
7. Selecione **Open with Live Server**.

O projeto será aberto automaticamente no navegador.
